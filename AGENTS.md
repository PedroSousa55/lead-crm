# Projeto Lead CRM

## Objetivo

Criar um CRM local para prospecção de clientes e abertura de conversas no WhatsApp.

## Stack

- Frontend: HTML5, CSS3 e JavaScript puro.
- Backend: Node.js + Express.
- Banco: MySQL local usando UniServer Zero.
- Driver MySQL: mysql2.
- Aplicação deve funcionar em localhost.
- Não usar React.
- Não usar Bootstrap.

## Estrutura

- frontend/
- backend/
- database/

## Backend

Organizar em:

- routes/
- controllers/
- models/
- config/

## Banco

- Usar .env para configuração.
- Não colocar senha diretamente no código.
- Não apagar banco ou tabelas sem confirmação.

## WhatsApp

- Usar links wa.me.
- Não enviar mensagens automaticamente.
- O usuário revisa e clica para enviar.

## Mensagens

- Humanizadas.
- Curtas e naturais.
- Personalizadas com dados reais do lead.
- Permitir variações de abordagem comercial.
- Evitar frases robóticas e elogios inventados.

## Interface

- Português-BR.
- Design moderno de CRM.
- Modo claro e escuro.
- Responsivo.

## Desenvolvimento

- Fazer por etapas.
- Testar antes de avançar.
- Corrigir erros encontrados.
